How it works

Upload once. Then just ask.

Doc Indexer reads your documents, classifies them and answers only from what the person asking is allowed to see.

  1. Upload documents

    Contracts, manuals, reports, policies or test reports are read in once and added to one shared index.

  2. Set permissions

    The AI suggests which role may see each document. You review it and can change every permission.

  3. Ask in your own words

    No keywords, and no need to know which document holds the answer.

  4. Answer with source

    Every statement points to the original page, with the cited passage highlighted.

Answers you can trust.

A language model sounds convincing even when it is guessing. Doc Indexer backs every statement with a source, respects permissions and says plainly what it is missing.

Summary with sources

Summarised briefly. Cited exactly.

Doc Indexer sums up the answer in a few sentences, even across several documents. Every statement carries a number. One click opens the original page with the cited passage highlighted.

Permissions per role

The AI suggests. You decide.

On upload, the AI classifies each document and suggests which role may see it. You review every permission and change it with one click. Settings that work well can be reused as a preset.

Same question, different role

Everyone sees only what they are allowed to see.

If someone asks about content that is not shared with their role, Doc Indexer says so openly and lists the documents they can see. It does not guess and it reveals nothing.

No migration: your file structure stays as it is. If you prefer, Doc Indexer works directly on your local storage.

    Frequently asked questions.

    Does Doc Indexer only work for real estate?

    No. The demo uses a building file as an example. The principle is the same for any document collection: machine documentation, operating manuals, handbooks, contracts, policies or quality records.

    Which documents can Doc Indexer read?

    PDF documents such as contracts, reports and manuals, as in the demo. Which other formats and sources you need is something we clarify in the intro call.

    Where are our documents stored?

    Wherever you decide: on servers in Germany, the EU or on-premise in your own infrastructure. We set out the location in the data processing agreement, which we draft per project for your stack and requirements.

    How are permissions managed?

    On upload, the AI suggests which roles may see each document. You review the suggestion and change any permission with one click. Settings that work well can be saved as a preset and reused for further documents.

    Can it connect to our existing file storage?

    Yes, that is what it is designed for: nothing needs to be migrated, your folder structure stays as it is, and it can work directly on your local storage. We agree in the intro call which systems to connect. If an interface is missing, we develop it.

    What happens if the answer is not in the documents?

    Then it says so. If a detail is missing, it flags it as open instead of guessing. If a relevant document is not shared with your role, you are told, without any of its content reaching the answer.
